# 🏦 Bank Management System

A robust, feature-packed Banking Management application developed in **Java** leveraging core **Object-Oriented Programming (OOP)** principles and relational database management.

## ✨ Features
- 🔐 **User Authentication:** Secure login and registration for customers and administrators.
- 💳 **Account Management:** Create, view, and update savings/current account details.
- 💸 **Transactions:** Fast deposits, withdrawals, and inter-account funds transfer.
- 📜 **Transaction History & Statements:** Detailed logs of all financial activities.

## 🛠️ Tech Stack
- **Language:** Java (JDK 17+)
- **Database:** MySQL
- **Architecture:** Model-View-Controller (MVC) / Modular OOP

## 🚀 Getting Started

### Prerequisites
- JDK 17 or higher
- MySQL Server

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Bhavy3594/Bank-Management-System.git
   ```
2. Setup the MySQL database using the provided SQL schema script.
3. Compile and run the main application entry point:
   ```bash
   javac Main.java
   java Main
   ```
